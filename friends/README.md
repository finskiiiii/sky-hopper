Lege hier die Fotos deiner Freunde ab.

Benutze diese Dateinamen:

- `friend-1.jpg`
- `friend-2.jpg`
- `friend-3.jpg`
- `friend-4.jpg`
- `friend-5.jpg`

Das Spiel nimmt pro Runde automatisch eines der vorhandenen Bilder.
Wenn du mehr Bilder willst, ergaenze die Liste `FRIEND_IMAGE_PATHS` in `game.js`.
